## How it is applied
`apply.py <bench-root>` is idempotent and drift-guarded: for each target it
no-ops if the file already has our bytes or already carries the upstream fix
markers (so a future version bump never double-applies), copies the vetted file
if the target is byte-identical to our pin, and fails the build loudly otherwise.
`apply.py --verify` asserts everything is fixed without writing. Drop the set
once we bump to frappe ≥ 16.31.0 / erpnext ≥ 16.32.0 (GHSA-2c6h stays until
upstream backports it).
